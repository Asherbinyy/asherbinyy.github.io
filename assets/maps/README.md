# Map data

`ne_110m_land.geojson` is Natural Earth 1:110m land data, version 5.1.2,
downloaded from the project's maintained `nvkelso/natural-earth-vector`
repository. Natural Earth data is public domain. The application uses geometry
only and makes no map or location network requests at runtime.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
