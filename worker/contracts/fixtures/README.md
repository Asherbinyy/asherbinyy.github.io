# Fixtures

Sanitized documents for tests and the local harness in `worker/dev/`.

**Nobody in here is real.** The owner's actual content lives in
`assets/content/` and belongs to him; browser verification of the panel runs
against these instead, so a screenshot of the editor can be attached to a
worklog without publishing his address, his phone number or his marks.

They are valid against `../content-schema.js` and deliberately uneven: some
optional fields are filled in and some are not, one interest has no note, one
application has no store listing, and one localised value has no Arabic. That
is what the real documents look like, and an editor that only works against a
complete document is not finished.
